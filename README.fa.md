## ⚡ نصب تک‌دستوری و خودکار

نصب و راه‌اندازی V2Raynix روی تمامی توزیع‌های لینوکس (**Ubuntu**, **Debian**, **CentOS**, **Fedora**, **Arch Linux**) تنها با اجرای **یک دستور** در ترمینال بدون نیاز به نصب Go، کامپایل یا پیش‌نیازهای پیچیده:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/ImMahdi/V2Raynix/main/scripts/install.sh)
```

### 🪄 مراحل انجام‌شده توسط اسکریپت نصب خودکار:
1. **تشخیص خودکار معماری سخت‌افزار:** شناسایی پردازنده‌های `x86_64` (`amd64`) و `aarch64` (`arm64`).
2. **بررسی و نصب نیازمندی‌های سیستمی:** اطمینان از وجود بسته‌های `curl`, `unzip`, `iptables`, `iproute2` و `ca-certificates`.
3. **دانلود و استقرار هسته‌های پایه:** دریافت آخرین نسخه رسمی **Xray-core** و **tun2socks** به همراه جدیدترین پایگاه‌های داده **GeoIP** و **GeoSite**.
4. **نصب باینری یکپارچه:** دانلود و استقرار فایل اجرایی مستقل `v2raynix` به همراه وب‌پنل کامپایل‌شده داخل آن در مسیر `/usr/local/bin/v2raynix`.
5. **تنظیم فایروال:** باز کردن پورت مدیریت وب `2080` در فایروال سرور (`ufw` یا `firewalld`).
6. **ایجاد سرویس systemd:** ثبت و راه‌اندازی دائمی سرویس پس‌زمینه `v2raynix.service`.

### 🌐 دسترسی به پنل مدیریت وب:
پس از پایان عملیات نصب، مرورگر خود را باز کرده و آدرس زیر را وارد کنید:
```text
http://<آدرس-آی‌پی-سرور>:2080
```
- **نام کاربری پیش‌فرض:** `admin`
- **کلمه عبور پیش‌فرض:** `admin` *(توصیه می‌شود در اولین ورود یا از طریق منوی ترمینال آن را تغییر دهید)*

## 💡 چرا V2Raynix؟

مدیریت کلاینت‌های پروکسی روی سرورهای لینوکسی فاقد رابط گرافیکی همواره با چالش‌ها و خطرات جدی همراه بوده است. ویرایش دستی فایل‌های پیچیده JSON، نبود مدیریت یکپارچه کارت شبکه مجازی تونل (TUN)، و بدتر از همه تغییر جداول مسیریابی پیش‌فرض لینوکس معمولاً منجر به **قطع شدن نشست فعال SSH و از دست رفتن دسترسی مدیر به سرور** می‌گردد.

**V2Raynix** با رویکردی مهندسی‌شده این مسائل را حل کرده است:
1. **مسیریابی ایمن ضد قطعی (Zero-Lockout Routing):** تشخیص خودکار پورت اتصال SSH، آی‌پی ورودی مدیر و گیت‌وی پیش‌فرض کارت شبکه فیزیکی تضمین می‌کند که ارتباط مدیریتی شما تحت هیچ شرایطی قطع نخواهد شد.
2. **حالت ایمن بازگشت خودکار ۱۲۰ ثانیه‌ای (Safe Mode):** هرگونه اعمال تغییر در مسیرهای شبکه یک تایمر شمارش معکوس را فعال می‌کند؛ در صورتی که کاربر تأییدیه نهایی را ارسال نکند، تنظیمات شبکه به‌صورت خودکار به حالت اولیه برمی‌گردد تا مانع از سیاهچاله شدن ترافیک سرور شود.
3. **استقرار تک‌باینری با صفر وابستگی:** کل داشبورد مدرن ری‌اکت در فایل اجرایی Go ادغام شده است (`go:embed`). به نصب Node.js، سرور Nginx یا پایگاه‌داده خارجی نیازی نیست.
4. **رابط متنی ترمینال (TUI):** منوی کنسول شکیل با کادربندی ANSI برای بازنشانی آسان کلمه عبور با قابلیت تایپ خاموش (بدون نمایش کاراکتر مثل دستور `sudo`) و مدیریت پورت و سرویس بدون نیاز به مرورگر.

## 🚀 امکانات و قابلیت‌های کلیدی

- **🌐 تونل‌سازی سراسری سرور (`tun2socks`):** هدایت شفاف و سراسری تمام ترافیک خروجی TCP و UDP سرور لینوکس از طریق کارت شبکه مجازی `tun0` به کانفیگ فعال پروکسی.
- **🛡️ سیستم دفاعی دولایه ضد قطعی ارتباط:** رول‌های مسیریابی کرنل باعث می‌شوند ارتباط SSH (پورت ۲۲ یا سفارشی)، ترافیک پورت پنل وب و اتصالات مستقیم بدون عبور از `tun0` مستقیماً از درگاه فیزیکی سرور عبور کنند.
- **⏱️ زمان‌سنج Safe Mode:** تایمر ۲ دقیقه‌ای حفاظت از پایداری شبکه در برابر کانفیگ‌های نادرست و مسدود شدن احتمالی.
- **⚡ پشتیبانی گسترده از پروتکل‌های مدرن:**
  - **VLESS:** پشتیبانی کامل از `xhttp`، `reality`، `xtls-rprx-vision`، `ws`، `grpc` و `tcp`.
  - **VMess:** پشتیبانی کامل AEAD با پروتکل‌های انتقالی WebSocket و TCP و هدرهای سفارشی.
  - **Trojan:** پیکربندی‌های استاندارد TLS و WebSocket.
  - **Shadowsocks:** متدهای رمزنگاری مدرن 2022 AEAD و نسخه‌های پیشین.
- **🧠 مسیریابی هوشمند و نرمال‌سازی خودکار دیتاهای جغرافیایی:** امکان تعریف رول‌های سفارشی دامنه و آی‌پی (مستقیم / عبور از پروکسی / مسدودسازی). اصلاح هوشمند نام‌گذاری‌ها (نظیر تبدیل خودکار `geosite:ir` به `geosite:category-ir` و `geoip:ir`) جهت جلوگیری از کرش سینتکس هسته Xray.
- **📊 عیب‌یابی لحظه‌ای نودها:** آزمایش تأخیر دوگانه شامل تست پینگ خام TCP و تست تاخیر اتصال واقعی لایه اپلیکیشن (HTTP Handshake Delay).
- **🖥️ منوی ترمینال با رمزنگاری ورودی:** منوی پیکربندی `v2raynix setup` با قابلیت مخفی‌سازی کامل کلمه عبور حین تایپ و اعتبارسنجی ورود مجدد رمز عبور.
- **🔄 بروزرسانی مستقیم هسته‌ها از داخل پنل:** مشاهده و آپدیت آنلاین هسته‌های `Xray-core` و `tun2socks` با اعتبارسنجی خودکار Checksum و امکان بازگشت در صورت بروز خطا.

## 🖥️ منوی تعاملی ترمینال (TUI)

برای تغییر یا بازنشانی کلمه عبور مدیر، اصلاح پورت وب، یا مشاهده سریع وضعیت سرویس بدون باز کردن مرورگر، کافیست در خط فرمان سرور تایپ کنید:

```bash
sudo v2raynix setup
```

```text
┌────────────────────────────────────────────────────────────┐
│                    V2RAYNIX SERVER SETUP                   │
├────────────────────────────────────────────────────────────┤
│  Service Status : ● Active (Running)                       │
│  Web Management : http://127.0.0.1:2080                    │
├────────────────────────────────────────────────────────────┤
│  [1] Change / Reset Admin Credentials                      │
│  [2] Change Web Panel Listening Port                       │
│  [3] Manage V2Raynix Service (Start / Stop / Restart)      │
│  [4] View Server Status & Diagnostics                      │
│  [0] Exit Setup                                            │
└────────────────────────────────────────────────────────────┘
```

> **نکته امنیتی:** در گزینه `[1]`، هنگام وارد کردن پسورد جدید هیچ کاراکتر یا علامتی روی مانیتور چاپ نمی‌شود (دقیقاً مشابه رفتار رمز عبور در دستور `sudo` لینوکس) و جهت اطمینان، تکرار کلمه عبور نیز دریافت و بررسی می‌گردد.

## 🌐 داشبورد تحت وب

رابط کاربری مدرن با تم تاریک، المان‌های شیشه‌ای و گرافیک روان:

- **داشبورد اصلی:** نمایش زنده سرعت آپلود/دانلود سرور، زمان اتصال، وضعیت کارت شبکه tun0 و تایمر شمارش معکوس حالت امن.
- **کانفیگ‌ها (پیکربندی):** وارد کردن سریع لینک‌های اشتراک استاندارد (`vless://`, `vmess://`, `trojan://`, `ss://`) یا کدهای JSON با امکان تست پینگ گروهی و تست تاخیر واقعی HTTP.
- **مسیریابی هوشمند:** ایجاد رول‌های دقیق دامنه یا رنج IP برای عبور مستقیم، عبور از پروکسی، یا مسدودسازی، با دکمه‌های آماده دور زدن سایت‌های ایرانی (`geosite:category-ir`, `geoip:ir`) و فیلتر تبلیغات (`geosite:category-ads-all`).
- **لاگ‌های زنده:** کنسول لاگ لحظه‌ای رویدادهای مسیریابی لینوکس، وضعیت پردازه‌ها و خروجی هسته Xray.
- **تنظیمات و بروزرسانی هسته:** تغییر پورت، مدیریت تایمر Safe Mode و امکان دانلود و ارتقای هسته‌های Xray و tun2socks با یک کلیک.

## ⚙️ پارامترها و سوییچ‌های خط فرمان (CLI)

```text
Usage: v2raynix [flags]
       v2raynix setup [subcommand flags]

Flags:
  -port int
        پورت دسترسی به رابط کاربری وب و API (پیش‌فرض: 2080)
  -data-dir string
        مسیر ذخیره تنظیمات و فایل‌های وضعیت (پیش‌فرض: /etc/v2raynix یا ./data)
  -init-password string
        مقداردهی مستقیم یا بازنویسی کلمه عبور مدیر
  -mock
        اجرا در حالت شبیه‌سازی بدون دستکاری کارت شبکه‌ها یا iptables لینوکس
  -version
        نمایش شماره نسخه نرم‌افزار و خروج
```

## 🛠️ کامپایل دستی از سورس کد (اختیاری)

<details>
<summary><b>جهت مشاهده دستورات ساخت دستی برای توسعه‌دهندگان کلیک کنید</b></summary>
<br/>

اگر مایل هستید به‌جای نصب خودکار، خودتان پروژه را از مبدا کدنویسی کامپایل نمایید:

### پیش‌نیازها:
- **Go:** نسخه 1.23 یا بالاتر
- **Node.js و npm:** نسخه 18 یا بالاتر (جهت کامپایل فرانت‌اند React)
- ابزارهای پایه ساخت لینوکس (Make / Bash)

### مراحل کامپایل گام‌به‌گام:

```bash
# ۱. دریافت سورس مخزن
git clone https://github.com/ImMahdi/V2Raynix.git
cd v2raynix

# ۲. بیلد فرانت‌اند ری‌اکت
cd web
npm install
npm run build
cd ..

# ۳. کامپایل باینری مستقل و یکپارچه Go
go build -ldflags="-s -w" -o bin/v2raynix ./cmd/v2raynix

# ۴. اجرای تستی در محیط شبیه‌ساز (Mock)
./bin/v2raynix -port 2080 -mock
```

## 🔒 نکات امنیتی و سلب مسئولیت

- **دسترسی روت:** اعمال تغییرات در مسیردهی سراسری سیستم لینوکس (`tun0`, `iptables`, `ip route`) نیازمند اختیارات روت (`CAP_NET_ADMIN`, `CAP_NET_BIND_SERVICE`) است.
- **سلب مسئولیت:** این نرم‌افزار به صورت «همان‌گونه که هست» و بدون هرگونه ضمانت ارائه می‌شود. مسئولیت رعایت قوانین و مقررات محلی بر عهده کاربر نهایی است.
